## 🚀 Featured Project

### [FrenchUp](https://github.com/drop-chik/french-app) — full-stack French learning platform

[![Live demo](https://img.shields.io/badge/▶_Live_demo-french--web--two.vercel.app-1f6feb?style=for-the-badge)](https://french-web-two.vercel.app)
[![Repo](https://img.shields.io/badge/Source-french--app-24292e?style=for-the-badge&logo=github)](https://github.com/drop-chik/french-app)

A complete language-learning web app I designed, built, and deployed myself:

- 🧠 **Spaced-repetition** vocabulary engine (SM-2 algorithm) with 8 study modes
- 📚 **Grammar** theory + interactive exercises, 🎧 **listening** comprehension, 🤖 **AI conversation** tutor (OpenAI, streaming via SSE)
- 🇫🇷 **1500+ CEFR-aligned words** (A1–A2) plus grammar & listening through B1, placement test, progress tracking & streaks
- 🔐 JWT auth (access token in memory + refresh token in httpOnly cookie), Zod request validation
- ⚙️ **CI/CD** — every push auto-deploys the frontend (Vercel) and backend (Railway)

> 🔒 I also maintain **farmi-agency-app** — an internal business CRM with marketing analytics and third-party API integration (Next.js · Fastify · PostgreSQL). Private repo — happy to walk through it on request.
